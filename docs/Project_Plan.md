# แผนงานโครงการพัฒนาเว็บไซต์ RotiBit

**ชื่อเว็บ:** RotiBit - แหล่งเรียนรู้คริปโตสำหรับคนไทย

**วัตถุประสงค์:** สร้างเว็บไซต์ให้ความรู้ด้าน Cryptocurrency สำหรับคนไทย โดยเน้นความปลอดภัยทางกฎหมาย (Compliance) ไม่ชี้นำการลงทุน และใช้ระบบ Affiliate ของแพลตฟอร์มที่ได้รับใบอนุญาตในไทย (Binance TH) อย่างถูกต้อง

**สถานะโครงการ:** กำลังดำเนินการ Phase 1 & 2 (วันที่ 31 กรกฎาคม 2026)

---

## 1. โครงสร้างและสถาปัตยกรรมเว็บไซต์ (Sitemap & Architecture)

เน้นการแบ่งหมวดหมู่เนื้อหาให้ชัดเจน จัดโครงสร้างแบบ Modular เพื่อให้ง่ายต่อการดูแลรักษา (Maintainability) โดยแยกส่วนประกอบหลัก (Header, Footer, Sidebar) ออกจากเนื้อหา 

*   **หน้าแรก (Home):** ภาพรวมของเว็บไซต์, ข่าวสารเทคโนโลยีบล็อกเชน, และปุ่ม Call-to-Action (CTA) สีแดงสำหรับสมัครใช้งาน
*   **ความรู้พื้นฐาน (Crypto 101):** อธิบายว่าคริปโตคืออะไร, บล็อกเชนทำงานอย่างไร, และคำศัพท์ที่ควรรู้ (Educational Content แท้ๆ)
*   **คู่มือการใช้งาน (How-to & Tutorials):** สอนวิธีใช้งานแอปพลิเคชันอย่างละเอียด เช่น วิธีสมัคร Binance TH, วิธียืนยันตัวตน (KYC), วิธีฝาก-ถอนเงิน (เน้นสอนเครื่องมือ)
*   **ข้อสงวนสิทธิ์ (Disclaimer / Terms):** หน้าสำคัญที่ระบุข้อจำกัดความรับผิดชอบทางกฎหมายอย่างละเอียด

---

## 2. แนวทางการออกแบบ (UI/UX & Styling)

ออกแบบโดยคำนึงถึงประสบการณ์ผู้ใช้ (UX) เป็นหลัก เพื่อลดความซับซ้อนของข้อมูลคริปโต 

*   **Framework:** พัฒนาด้วย HTML5 และ Bootstrap 5 เพื่อให้รองรับการแสดงผลทุกหน้าจอ (Responsive Web Design)
*   **Background (พื้นหลัง):** ใช้สีขาว (`#FFFFFF`) หรือสีเทาอมม่วงอ่อนๆ (`#f8f9fa`) เพื่อให้ดูสะอาดตาและอ่านง่าย
*   **Typography (ตัวอักษร):** 
    *   **หัวข้อ (Headers):** ใช้สีน้ำเงินเข้ม (`#1B1464`) เพื่อดึงดูดสายตาและสร้างความน่าเชื่อถือ
    *   **เนื้อหาหลัก (Body text):** ใช้สีดำ หรือเทาเข้ม (`#333333`)
    *   **ฟอนต์ (Font):** ใช้ฟอนต์ตระกูล Sans-serif ที่อ่านง่าย เช่น Prompt (Google Fonts)
*   **Buttons & CTA (ปุ่มกด):** ใช้สีแดง/ส้มแดง (`#F64548`) เพื่อให้ปุ่มสมัครง่ายต่อการสังเกตและกระตุ้นการคลิก
*   **Logo:** ใช้โลโก้ CryptoEdu ในส่วน navbar
*   **Favicon:** ใช้ไฟล์ `assets/ico/fav.png`

## 3. มาตรการควบคุมเนื้อหาและกฎหมาย (Compliance & Risk Control)

เพื่อให้ปลอดภัย 100% ตามข้อกำหนดของ ก.ล.ต. ไทย กำหนดเป็นมาตรฐานการปฏิบัติงาน (SOP) ในการนำเข้าเนื้อหา:

1.  **Global Disclaimer Component:** แสดงข้อความเตือนความเสี่ยงใน Footer ของทุกหน้า (ยังกำลังทำ)
2.  **Whitelist Link Validation:** ตรวจสอบโค้ด `href` ทั้งหมดในเว็บไซต์ว่าชี้ไปที่ **Binance TH** เท่านั้น ห้ามมีลิงก์หลุดไปที่แพลตฟอร์ม Global ที่ไม่ได้รับอนุญาต
3.  **Content Audit:** ห้ามใช้คำศัพท์เชิงชี้นำราคา เช่น "ซื้อเลย", "กำไรแน่นอน", "เหรียญเด็ด" ให้ใช้คำว่า "เรียนรู้วิธีการใช้งาน", "ขั้นตอนการแลกเปลี่ยน", หรือ "เริ่มต้นศึกษา" แทน
4.  **Affiliate Disclosure:** ระบุชัดว่า Binance TH by Gulf Binance เท่านั้น

## 4. แผนการดำเนินงาน (Implementation Plan)

แบ่งระยะการดำเนินงานออกเป็นเฟสที่ชัดเจน เพื่อให้การบริหารโครงการมีประสิทธิภาพและสามารถควบคุมคุณภาพ (Quality Control) ได้ในทุกขั้นตอน

### Phase 1: Project Setup & UI Development ✅ เสร็จแล้ว

*   **Task 1.1:** ✅ สร้างโครงสร้าง HTML5 Boilerplate และเชื่อมต่อ Bootstrap CSS/JS
*   **Task 1.2:** ✅ กำหนดตัวแปรโทนสี (ขาว, น้ำเงิน, ดำ, แดง) และสร้าง Global CSS Class
*   **Task 1.3:** ✅ พัฒนา Layout หลักของเว็บไซต์ (Navbar ที่มีโลโก้, Footer, Hero Section, Features Section)
*   **Task 1.4:** ✅ Setup Docker + docker-compose.yml พร้อม volume mount เพื่อง่ายต่อการพัฒนา
*   **Deliverable:** โครงสร้างหน้าเว็บพื้นฐานที่รันได้ที่ `http://localhost:8089` พร้อมการเปลี่ยนแปลงทันที

### Phase 2: Content Generation & Compliance Check 🔄 กำลังดำเนินการ

*   **Task 2.1:** 🔄 จัดทำและตรวจสอบเนื้อหา "ข้อสงวนสิทธิ์ (Disclaimer)" 
    - ✅ เนื้อหา disclaimer.html ครบถ้วนและถูกต้องตามกฎหมาย
    - 🔄 ต้องแก้ไข: เปลี่ยนชื่อเว็บจาก "RotiBit" เป็น "CryptoEdu" ทุกแห่ง
    - 🔄 ต้องแก้ไข: ตรวจสอบ alt text ในโลโก้ให้ตรงกับ CryptoEdu
*   **Task 2.2:** ⏳ จัดทำเนื้อหา "ความรู้พื้นฐาน (Crypto 101)" แบบ Educational
*   **Task 2.3:** ⏳ จัดทำเนื้อหา "คู่มือการใช้งาน (Tutorials)" แบบ Step-by-step
*   **Task 2.4:** ⏳ ทำการประเมินเนื้อหา (Content Audit) ทั้งหมดเพื่อรับรองว่าไม่มีข้อความชี้นำการลงทุน
*   **Deliverable:** เนื้อหาเว็บไซต์ฉบับสมบูรณ์ที่ผ่านการตรวจสอบด้าน Compliance

### Phase 3: Affiliate Integration & Tracking ⏳ ยังไม่ทำ

*   **Task 3.1:** นำ Referral Link ของ Binance TH ไปฝังในปุ่ม CTA บนหน้าเพจที่กำหนด
*   **Task 3.2:** ติดตั้งเครื่องมือติดตามผล (Analytics / Tracking Tags) เพื่อวัดผลการคลิก (CTR)
*   **Deliverable:** ระบบลิงก์ Affiliate ที่พร้อมใช้งานและสามารถวัดผลได้

### Phase 4: User Acceptance Testing (UAT) & QA ⏳ ยังไม่ทำ

*   **Task 4.1:** ตรวจสอบการแสดงผลบนอุปกรณ์ที่หลากหลาย (Mobile, Tablet, Desktop)
*   **Task 4.2:** ทดสอบการทำงานของลิงก์และปุ่มทั้งหมด (Link Validation)
*   **Task 4.3:** ดำเนินการ UAT เพื่อยืนยันความถูกต้องของข้อมูล รูปแบบ และฟังก์ชันการทำงานทั้งหมด
*   **Deliverable:** รายงานผลการทดสอบ (QA/UAT Sign-off)

### Phase 5: Deployment & Go-Live ⏳ ยังไม่ทำ

*   **Task 5.1:** อัปโหลดไฟล์ขึ้นสู่โปรดักชันเซิร์ฟเวอร์ (Production Environment)
*   **Task 5.2:** ตรวจสอบความปลอดภัยพื้นฐาน (SSL Certificate / HTTPS)
*   **Task 5.3:** เปิดตัวเว็บไซต์และติดตามการทำงาน (Post-Go-Live Support)
*   **Deliverable:** เว็บไซต์ที่เปิดใช้งานจริงอย่างสมบูรณ์
