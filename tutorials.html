คู่มือการใช้งาน: เริ่มต้นกับ Binance TH

คำแนะนำแบบทีละขั้นตอน (Step-by-step) สำหรับการสมัคร ยืนยันตัวตน และการทำธุรกรรม

📑 เนื้อหาในหน้านี้:
  • 1. วิธีสมัครบัญชี
  • 2. ยืนยันตัวตน (KYC)
  • 3. ตั้งค่าความปลอดภัย
  • 4. ฝากเงิน
  • 5. ซื้อคริปโต
  • 6. ถอนเงิน
  • 7. ข้อควรระวัง

1 วิธีสมัครบัญชี Binance TH

ขั้นตอนแรกคือการสร้างบัญชี Binance TH ที่ได้รับอนุญาตอย่างถูกต้องในประเทศไทย

1.1เข้าไปที่เว็บไซต์ Binance TH

ไปที่ binance.th หรือคลิกลิงก์สมัครในหน้านี้

1.2กรอกข้อมูลการสมัครสมาชิก

  • กรอก Email ที่ใช้งานจริง (จะเป็นชื่อผู้ใช้ของคุณ)
  • สร้าง รหัสผ่าน ที่ปลอดภัย (ตัวใหญ่+ตัวเล็ก+ตัวเลข+สัญลักษณ์)
  • ยืนยันบัญชีของคุณผ่านอีเมล (ตรวจสอบ Inbox)

1.3ยืนยันอีเมล

Binance จะส่ง Link ยืนยันถึงอีเมลของคุณ คลิกเพื่อยืนยันบัญชี

💡 เคล็ดลับ: ตรวจสอบ Spam folder ถ้าไม่เห็นในหนังสือหลัก
หน้า Login

กรอก Email และรหัสผ่าน แล้วคลิก Sign In

✅ เสร็จสิ้น: บัญชีของคุณได้รับการสร้าง สามารถล็อกอินได้แล้ว

2 ยืนยันตัวตน (KYC - Know Your Customer)

เพื่อให้ปลอดภัยและปฏิบัติตามกฎหมาย Binance ต้องการข้อมูลตัวตนของคุณ

2.1เตรียมเอกสาร

  • บัตรประชาชน (หรือพาสปอร์ต) - ต้องไม่หมดอายุ
  • ถ่ายรูปบัตรทั้งด้านหน้าและด้านหลัง
  • ถ่ายรูปตนเองถือบัตรประชาชน (ชัดเจนและอ่านได้)

2.2เข้าไปหน้า Verification

ในบัญชี Binance ของคุณ ไปที่ Account → Verification

2.3กรอกข้อมูลส่วนบุคคล

  • ชื่อ-นามสกุล (ต้องตรงกับบัตรประชาชน)
  • วันเดือนปีเกิด
  • ประเทศสัญชาติ (ไทย)
  • ที่อยู่ที่อยู่อาศัยในปัจจุบัน

2.4อัปโหลดไฟล์

  • อัปโหลดภาพบัตรประชาชนด้านหน้า
  • อัปโหลดภาพบัตรประชาชนด้านหลัง
  • ถ่ายรูป Selfie ถือบัตรประชาชน (ต้องเห็นหน้า+บัตร+มือ)

2.5รอการอนุมัติ

Binance จะตรวจสอบข้อมูลของคุณ โดยทั่วไปใช้เวลา 1-3 วัน ทำการ

⏱️ รอสักครู่: หากไม่อนุมัติ Binance จะแจ้งเหตุผลให้ทราบ อาจต้องอัปโหลดซ้ำ
หน้า Verification

อัปโหลดบัตรประชาชน และรูป Selfie

✅ เสร็จสิ้น: บัญชียืนยันแล้ว! สามารถทำธุรกรรมได้

3 ตั้งค่าความปลอดภัย (2FA)

เพื่อปกป้องบัญชีของคุณจากการโจรกรรม ต้องเปิด 2-Factor Authentication (2FA)

3.1ติดตั้งแอปสร้างโค้ด

  • ดาวน์โหลด Google Authenticator หรือ Authy (ฟรีในทั้ง iOS และ Android)
  • ติดตั้งแอปในโทรศัพท์ของคุณ

3.2เปิด 2FA ใน Binance

ไปที่ Account → Security → 2FA คลิก "Enable"

3.3สแกน QR Code

  • ใช้ Google Authenticator สแกน QR Code ที่ Binance แสดง
  • แอปจะสร้างโค้ด 6 หลักแบบอัตโนมัติทุก 30 วินาที

3.4บันทึก Backup Code

Binance จะให้ Backup Codes มา บันทึกไว้ที่ปลอดภัย (ถ้าสูญหายโทรศัพท์ใช้เพื่อกู้คืน)

⚠️ สำคัญมาก: เก็บ Backup Codes ไว้ในที่ปลอดภัย ห้ามบอกใครเด็ดขาด
หน้า 2FA Setup

สแกน QR Code ด้วย Google Authenticator

✅ เสร็จสิ้น: บัญชีปลอดภัยแล้ว!

4 ฝากเงิน (Deposit)

วิธีการฝากเงินบาท (THB) เข้าบัญชี Binance

4.1ไปหน้า Wallet

ในบัญชี Binance ไปที่ Wallet → Fiat and Spot

4.2เลือก "Deposit"

คลิกปุ่ม "Deposit" แล้วเลือก Thailand Baht (THB)

4.3เลือกวิธีการ

  • Bank Transfer: โอนเงินจากบัญชีธนาคารของคุณ
  • e-Wallet: ผ่านพromptpay, True Money Wallet เป็นต้น

4.4กรอกจำนวนเงิน

ป้อนจำนวนเงินที่ต้องการฝาก แล้วคลิก "Next"

💰 ข้อมูล: ค่าธรรมเนียมอาจแตกต่างกันไป ตรวจสอบก่อนยืนยัน

4.5โอนเงินและรอตรวจสอบ

Binance จะบอกหมายเลขบัญชีหรือ QR Code สำหรับโอนเงิน ทำการโอนตามที่ระบุ

เงินจะเข้าบัญชี Binance ภายใน 10 นาที ถึง 1 วัน ทำการ ขึ้นอยู่ับธนาคาร

หน้า Deposit

ตรวจสอบบัญชีธนาคารและจำนวนเงิน

✅ เสร็จสิ้น: เงินของคุณอยู่ใน Binance แล้ว!

5 ซื้อคริปโต

หลังจากมีเงินในบัญชี สามารถซื้อคริปโตได้

5.1ไปหน้า Buy Crypto

คลิก "Buy Crypto" หรือ "Trade" ในเมนู

5.2เลือกคริปโต

  • เลือก Bitcoin (BTC) หรือ Ethereum (ETH) สำหรับมือใหม่
  • บางคนเลือกคริปโตอื่น ๆ แต่ควรจะศึกษาก่อน

5.3ป้อนจำนวน

ป้อนจำนวนเงินไทยบาท (THB) หรือจำนวนคริปโตที่ต้องการ

5.4ตรวจสอบและยืนยัน

ตรวจสอบ:

  • จำนวนคริปโตที่จะได้รับ
  • ค่าธรรมเนียม
  • ราคาปัจจุบัน

5.5ส่วนคริปโต

คลิก "Confirm" และใส่โค้ด 2FA (จาก Google Authenticator)

เสร็จสิ้น! คริปโตของคุณอยู่ในกระเป๋าแล้ว

หน้า Trading

เลือกคริปโต ป้อนจำนวน และยืนยัน

✅ เสร็จสิ้น: คุณเป็นเจ้าของคริปโตแล้ว!

6 ถอนเงิน (Withdrawal)

วิธีการถอนเงินหรือคริปโตออกจาก Binance

6.1ไปหน้า Withdraw

ไปที่ Wallet → Fiat and Spot → Withdraw

6.2เลือกวิธีการถอน

  • Bank Transfer: โอนเงินกลับเข้าบัญชีธนาคารของคุณ
  • Withdraw Crypto: ถ่ายโอนคริปโตไปยังกระเป๋า (Wallet) อื่น

6.3กรอกข้อมูล

กรอกข้อมูลธนาคารของคุณหรือที่อยู่กระเป๋าคริปโต

6.4ยืนยัน 2FA

ใส่โค้ด 2FA เพื่อยืนยัน

6.5รอการประมวลผล

เงินจะออกจาก Binance ภายใน 1-3 วันทำการ ขึ้นอยู่กับธนาคาร

หน้า Withdrawal

ใส่ข้อมูลธนาคารและจำนวนเงิน

✅ เสร็จสิ้น: เงินของคุณถูกถอนออก!

7 ข้อควรระวัง และเคล็ดลับความปลอดภัย

ความปลอดภัยที่ส่วนใจ

ใช้ 2FA, รหัสผ่านแข็งแรง, ตรวจสอบ URL ก่อนล็อกอิน

⚠️ ความปลอดภัยอันดับหนึ่ง
  • ห้ามบอกรหัสผ่าน - Binance จะไม่เคยขอรหัสผ่านของคุณ
  • ห้ามเปิดลิงก์ที่สงสัย - อาจเป็น Phishing ที่จะขโมยข้อมูลของคุณ
  • ห้ามแนะนำ Private Key - ใครก็ตามที่มี Private Key สามารถเข้าไปได้ทั้งหมด
  • เปิด 2FA เสมอ - ป้องกันการเข้าไปโดยไม่ได้รับอนุญาต
💡 เคล็ดลับ
  • ใช้รหัสผ่านที่แข็งแรง - ตัวใหญ่ + ตัวเล็ก + ตัวเลข + สัญลักษณ์
  • ตรวจสอบ URL - ตรวจสอบให้แน่ใจว่า URL คือ binance.th
  • ใช้ VPN หากจำเป็น - เมื่อใช้ WiFi สาธารณะ
  • อัปเดต Software - เก็บ Operating System และแอปเป็นเวอร์ชันล่าสุด
  • เก็บ Backup Code - เก็บ Backup Code ของ 2FA ในที่ปลอดภัย
