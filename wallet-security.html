ประเภทกระเป๋า (Wallets)

วิธีการเก็บรักษาคริปโตให้ปลอดภัย

กระเป๋า (Wallet) คือที่เก็บคริปโตของคุณ การเลือกกระเป๋าที่เหมาะสมเป็นเรื่องสำคัญต่อความปลอดภัย

Hot Wallet (กระเป๋าอุ่น)

นิยาม: กระเป๋าที่เชื่อมต่อกับอินเทอร์เน็ตตลอดเวลา

ตัวอย่าง:

  • Exchange Wallet (Binance, Coinbase) - กระเป๋าที่แพลตฟอร์มจัดเตรียม
  • Mobile Wallet (Trust Wallet, MetaMask) - แอปบนมือถือ
  • Web Wallet - เว็บไซต์
✅ ข้อดี
  • สะดวก ใช้งานง่าย
  • ทำธุรกรรมได้ทันที
  • รองรับหลายคริปโต
❌ ข้อเสีย
  • มีความเสี่ยง (แฮก)
  • ไม่ควรเก็บจำนวนมาก
  • ต้องพึ่งเซิร์ฟเวอร์
💡 ใช้ได้กับ: การซื้อขาย เงินจำนวนน้อย (ทำงาน)

Cold Wallet (กระเป๋าเย็น)

นิยาม: กระเป๋าที่ไม่เชื่อมต่ออินเทอร์เน็ต

ตัวอย่าง:

  • Hardware Wallet (Ledger, Trezor) - อุปกรณ์โลหะเล็กๆ
  • Paper Wallet - พิมพ์ private key ลงกระดาษ
  • Air-gapped Device - คอมพิวเตอร์ที่ตัดการเชื่อมต่ออินเทอร์เน็ต
✅ ข้อดี
  • ปลอดภัยที่สุด
  • ไม่เสี่ยงต่อแฮก
  • เก็บได้นาน
❌ ข้อเสีย
  • ใช้งานซับซ้อน
  • ต้องซื้ออุปกรณ์
  • ทำธุรกรรมช้า
💡 ใช้ได้กับ: เก็บเงินระยะยาว (เหรียญจำนวนมาก)

Self-Custody vs Exchange Custody

Self-Custody (เก็บเอง)

คุณมี Private Key และควบคุมคริปโตทั้งหมด

  • ✅ ควบคุมคริปโตจริงๆ
  • ⚠️ ความรับผิดชอบเต็มที่ (หากลืมรหัส = หลุดตลอดไป)
Exchange Custody (เก็บไว้ที่แพลตฟอร์ม)

แพลตฟอร์มเก็บคริปโตให้ คุณเพียงใช้ username & password

  • ✅ สะดวก ทำธุรกรรมเร็ว
  • ⚠️ เสี่ยงถ้าแพลตฟอร์มล้มเหลว
💡 คำแนะนำ: ใช้ทั้งสองวิธี - เก็บสัดส่วนใหญ่ใน Cold Wallet (ปลอดภัย) และบางส่วนใน Hot Wallet (สะดวก)
🔒 เคล็ดลับความปลอดภัยกระเป๋า
  • ✅ Backup Private Key: เก็บสำเนา Private Key ไว้ที่ปลอดภัย (Paper หรือ USB)
  • ✅ Use Strong Password: รหัสผ่านต้องยาว (16+ ตัว) และซับซ้อน
  • ✅ Enable 2FA: เปิด Two-Factor Authentication บน Wallet และ Exchange
  • ✅ Verify Address: ตรวจสอบ Address ก่อนส่งเงิน (คัดลอกผิดวิธี)
  • ❌ Never Share Private Key: ห้ามบอกให้ใครรู้ เด็ดขาด!
  • ❌ Don't Use Public WiFi: ห้ามเข้า Wallet บน WiFi สาธารณะ
